The score moves in the right direction for the observed policy improvements and degradations, but **this gym does not provide a useful test of better research**. A genuine ensemble improves the weaker setting, yet its gain is smaller than the reference seed spread. The base setting is already saturated. An untrained constant policy and exhaustive search match the ensemble exactly. Missing-result filtering also lets a method that fails an entire setting tie the reference.

The reproduction **does beat its ordinary-DQN baseline in the reported direction on the gym's toy environments**: base 1.500000 versus -2.690333; weaker-bias 0.940444 versus -1.505000. This is not a reproduction of the paper's Atari results. Reading the local paper and current code identified these departures:

- Twelve masked Atari games become two variants of a six-state, two-action, six-step CMDP. State progression is deterministic and independent of the action; a single safe action is optimal everywhere. Hidden contexts are generated Bernoulli variables rather than information occluded from Atari images.
- Nature-DQN convolutional networks, 64×64 image preprocessing, frame stacking, and learned diamond/sebulba demonstrators become one-hot states, a two-layer width-16 MLP, and a hand-coded demonstrator with fixed 0.05 exploration.
- The paper collects demonstrator transitions while training with replay. The gym generates a complete fixed replay dataset before optimization. Its 500 episodes supply 3,000 transitions, versus the paper's 1M environment steps, 20 parallel environments, and 100K replay capacity.
- Batch size 512 becomes 64; learning rate 5e-4 becomes 1e-3; the gym uses 1,000 updates, discount 0.95, target updates every 100 optimization steps, and three training seeds rather than five. Atari return evaluation becomes undiscounted six-step returns over the fixed toy settings.
- The paper estimates the worst next state by sampling possible states; the gym enumerates all six states. Its finite-horizon implementation masks terminal bootstrapping for the logged-action target while the alternate-action target always bootstraps. These terminal conventions are additional toy-environment choices.
- The actual all-action pessimistic Bellman update and Double-DQN selection/evaluation are present. The scaled settings and procedural changes above limit what the resulting baseline advantage establishes about the paper.

The baseline comparison leaves room above ordinary confounded DQN, but **a simple constant baseline already attains the optimum**, so it does not leave useful room for research beyond the reference. There are only 2^6 = 64 deterministic policies per setting. The [brute-force shortcut](redteam/shortcut_bruteforce_visible/shortcut_search.json) enumerated every one, computed its expected return from the visible generator, selected the all-safe policy, and then achieved 1.500000 / 1.200000 through the actual hidden test. No held-out seeds, rollouts, labels, paper contents, or hidden evaluator details were used to construct that shortcut. The public reward model itself exposes the answer. Increasing only the number of states would not fix the constant-policy solution.

All metric ceilings need to be distinguished from episode-wise reward maxima. Here “optimal mean” means the maximum expected interventional return over legal policies in the original CMDP. It is 6 × the safe reward, since each risky action has strictly lower expected reward. The corresponding optimal lower-tail return is attainable by the deterministic safe policy.

The empty-policy shortcut demonstrates a concrete constraint-weighting failure under the specified normalization. Recalculate the rank using just two **actually run** attempts—the reference rerun and empty-policy shortcut—as the normalization cohort. It scores **+1.650000**, despite zero coverage and validity and no explicit decisions. Base explicit-safe coverage contributes -0.2; weaker-bias benefits contribute +2.05 and weaker-bias explicit coverage contributes -0.2. This uses coefficient magnitudes and standardized improvements, not units. In the full audit cohort it loses instead. Consequently, merely adding low-weight structural metrics does not ensure a method that violates the task loses. Safe/risky DQN on the intact, fully reported problem does score clearly below the reference; omission and soft constraints defeat that guarantee.

The hidden test does **not** write every method on disk into `results`. It evaluates artifacts but filters rows through editable `scoring/scores_train.json` ([filter](eval/test/evaluate_cmdp.py#L134)). The partial-manifest run retains the failed policy on disk and omits it from test output with exit 0. The missing-artifact check validates only entries the agent retained in that manifest. It does not require both experiments independently of the agent's choices. It also does not synthesize worst values for failures: a malformed artifact aborts before the final score write ([write](eval/test/evaluate_cmdp.py#L153)), leaving old scores behind. A failed job should not be credited on this evidence, but the required worst-value output contract is absent.

There is no separately loaded fixed learned detector, pretrained reference network, or model cache in this gym to retrain. The fixed asset consumed by the evaluator is the CMDP implementation and its parameter table in editable `data/`; replacing that asset was tested above. The comparison-side checks were exercised by swapping the environment variant and changing that reward table. Score, success, timing, impossible-value, empty-output, and null-output cases were also actually run. Shortcuts were constructed from the future agent's visible files; the paper and hidden evaluator were used only for the analyst's reproduction and scoring checks. Original method access is needed only for the improvement-mode scientific variants.

The next iteration should make the task nontrivial before adjusting weights: a constant visible action must not solve every setting, and the reference should leave measurable headroom beyond training-seed spread. Pin test environment parameters and experiment/variant mappings in restored test-owned code; require every expected experiment independently of the train manifest; validate run identities before averaging artifacts; reject or assign explicit worst metrics to invalid, incomplete, and failed submissions; and clear old score files before evaluation. Coverage/validity constraints need enforcement that cannot be traded away through normalization. These are recommendations only; this audit leaves the gym unchanged.
